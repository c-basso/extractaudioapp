使い方

iPhoneで動画から音声を抽出する方法

4回のタップで動画からMP3・M4Aへ。アプリからでも、写真の「共有」からでも始められます。

  1. 1

    動画を選ぶ

    アプリを開いて写真やファイルから動画を選択。または、動画の「共有」をタップしてアプリを選びます。

  2. 2

    必要ならトリミング

    「動画をトリミング」をタップし、黄色のマーカーをドラッグして必要な部分だけ残します（任意）。

  3. 3

    「音声を抽出」をタップ

    音声トラックがiPhone上で数秒のうちにMP3またはM4Aに変換されます。

  4. 4

    保存・共有

    音声を「ファイル」に保存したり、AirDropや他のアプリに送ったりできます。ファイルはすべてライブラリに残ります。

よくある質問

動画の音声についてよくある質問

iPhoneで動画から音声を抽出するには？

動画から音声抽出⁺を開き、動画を選んで、必要ならトリミングしてから「音声を抽出」をタップします。音声トラックがMP3またはM4AでiPhoneに保存されます。写真の「共有」から始めることもできます。

詳しく見る →

iPhoneで動画をMP3に変換するには？

「共有」で動画をアプリに送り、「音声を抽出」をタップしてMP3を選びます。ファイルは端末に残り、「ファイル」への保存やAirDrop、他のアプリへの送信ができます。

詳しく見る →

iPhoneでMP4をMP3に無料で変換できますか？

はい。「ファイル」または写真でMP4を開き、アプリに送ってMP3で書き出します。基本の変換は無料です。

詳しく見る →

iPhoneで撮ったMOV動画を音声にするには？

iPhoneのカメラはMOV形式で撮影します。写真からクリップをアプリに送り、MP3またはM4Aで音声を書き出します。

詳しく見る →

動画の音声をM4Aで保存できますか？

はい、抽出時にM4Aを選んでください。Apple純正の形式で、MP3より軽く、着信音やGarageBandに最適です。

詳しく見る →

アプリなしでiPhoneの動画から音声を抽出できますか？

はい。ショートカットで「メディアをエンコード」と「オーディオのみ」を使えば可能です。ただしM4Aのみでトリミングもできないため、MP3や短い部分ならアプリの方が速いです。

詳しく見る →

オンラインで動画から音声を抽出しても安全ですか？

オンラインサービスでは動画を外部のサーバーにアップロードする必要があります。動画から音声抽出⁺はiPhone内で変換するので、動画が端末の外に出ることはありません。

詳しく見る →

iPhoneで動画から音楽だけを取り出すには？

動画をアプリに送り、曲の部分だけトリミングして「音声を抽出」をタップします。自分で撮影した動画や、権利を持つ動画の音楽だけを保存してください。

詳しく見る →

動画の音声の一部だけを抽出できますか？

はい。「動画をトリミング」で必要な範囲を選んで抽出すれば、その部分だけが保存されます。

詳しく見る →

画面収録の音声だけを取り出すには？

画面収録は写真に動画として保存されます。アプリに送って音声を抽出してください。無音の場合は、収録時にマイクがオフになっていました。

詳しく見る →

講義の動画を音声で聴くには？

講義の動画をMP3に変換して「ファイル」に保存しましょう。画面を消したままオフラインで聴けて、容量もずっと少なくて済みます。

詳しく見る →

iPhoneで動画から着信音を作れますか？

はい。音声を30秒以内にトリミングして「ファイル」に保存し、iOS 26なら「共有」→「着信音として使用」をタップします。それ以前のiOSではGarageBandを使います。

詳しく見る →
